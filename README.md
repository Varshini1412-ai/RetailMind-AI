# RetailMind AI
*AI-powered sentiment analysis and product recommendations for online retailers.*

---

## Overview
RetailMind AI is a web app that analyzes customer reviews using sentiment analysis and generates personalized product recommendations. It helps online retailers boost trust, improve customer experience, and increase conversions by turning raw feedback into actionable insights.

---

## Features
- Sentiment analysis (positive, negative, neutral) on customer reviews  
- Personalized product recommendations based on feedback trends  
- Interactive dashboard with visual insights  
- Lightweight web app demo for easy use  

---

## Built With
- **Python** – core language for ML and backend  
- **Flask/Django** – web framework  
- **scikit-learn / Hugging Face Transformers** – machine learning & NLP models  
- **NLTK / spaCy** – text preprocessing and tokenization  
- **SQL** – dataset handling  
- **Plotly / Matplotlib** – visualization  
- **HTML / CSS / JavaScript** – front-end design  
- **Cloud Deployment (Heroku / Render / Azure Free Tier)** – hosting
